# MCU UART Protocol Host Test

`mcu_uart_protocol.c` is portable C and has no Pico SDK dependency. Run its
tests before connecting it to the Pico UART driver:

```bash
make -C firmware/mcu_uart_link test
```

The test covers:

- the packet bytes and CRC generated by the Python harness;
- one-byte and concatenated stream input;
- preamble resynchronization;
- invalid version, type, and length fields;
- CRC rejection followed by a valid packet;
- sequence gap and duplicate counters.

The packet callback payload points into parser-owned storage and is valid only
for the duration of the callback.
