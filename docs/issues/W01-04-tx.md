# W01-04 tx.c（固定レート送信 + seq/timestamp付与）実装メモ

## 対象イシュー
- Issue: W01: tx.c（固定レート送信 + seq/timestamp付与） #4
- Parent: [EPIC] W01 - UDP基礎通信基盤の構築（Frame v0 + 計測基礎） #1

## 目的
指定レートでUDPを送れる最小送信機を作る。
rx側で計測可能にするため、FrameV0 に seq と timestamp_ns を付与する。

## 実装内容（今回）
- tx のCLI引数解析
  - `--dst-ip`
  - `--dst-port`
  - `--rate-hz`
  - `--duration-sec`
  - `--log-path`
- UDPソケット生成（AF_INET / SOCK_DGRAM）
- 宛先IPv4アドレス構築（`sockaddr_in` + `inet_pton`）
- 固定レート送信ループ（絶対時刻ベース）
  - `clock_gettime(CLOCK_MONOTONIC, ...)`
  - `clock_nanosleep(CLOCK_MONOTONIC, TIMER_ABSTIME, ...)`
- `FrameV0` への値設定
  - `seq` を送信ごとに単調増加
  - `timestamp_ns` を送信直前のユーザ空間時刻で設定
- 実行ログ出力
  - `frame_v0` 情報
  - `tx start`
  - `tx summary`
  - `tx end`

## 設計判断（今回固定したこと）
- timestamp は「送信直前のユーザ空間時刻」を使う
  - カーネルが実際にNICへ出した時刻ではない
  - 後続の説明用に、計測限界として明示する
- レート制御は相対sleepではなく絶対時刻スケジューリングを採用
  - ドリフトを減らし、長時間でのレート安定性を上げる
- 時刻取得ヘルパーは out引数方式
  - 戻り値を成功/失敗に使い、値はポインタに格納する
  - エラー処理が明確になる

## AC判定（#4）

  - PASS

  - PASS（コード上実装）

- timestamp が ns で取得され Frame に入っている
  - PASS（コード上実装）
  - 実観測確認は rx 実装後に実施
- 送信レート変更がCLI引数でできる
  - PASS（CLI実装済み）

## 実施テスト

- `./bin/tx --help`
- `--help` は未定義のため `unrecognized option '--help'` の後に Usage 表示

### 2. 10秒送信（100Hz）
