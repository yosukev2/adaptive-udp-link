# W08 socket buffer tiny sweep summary

## 結論

- 30 runs すべて `run_validity=ok`。
- `SO_RCVBUF requested=100 / 512 / 1024` は、いずれも `actual=2304` に丸められた。kernel 側の最小値に当たっている可能性が高い。
- `requested=4096` は `actual=8192`、`requested=8000` は `actual=16000` になった。
- `rate_hz=14000` でも missing は小さく、今回の tiny sweep では #130 の大きな missing は再現していない。
- したがって、#130 の missing 増大を単純に「buffer が 8192 より小さかったため」と断定する材料にはならない。条件差、実行時揺らぎ、ログ取得条件、または別要因を切り分ける必要がある。
